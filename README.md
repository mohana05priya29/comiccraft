# ComicCraft - AI Comic Generator

ComicCraft is an innovative web application that helps you create amazing comics using AI.

## Features
- Generate comics with AI (Gemini Flash & Gemini Pro)
- Preview your comics before export
- Font manager for comic styles
- Export manager to download comics
- Image generator for comic creation

## Files in this Project
- comic_preview.html - Preview page
- export_success.html - Export success page
- exporters.py - Export functionality
- gemini_flash.py & gemini_pro.py - AI integration
- image_generator.py - Image generation

## Technologies Used
- Python (Flask)
- HTML, CSS, JavaScript
- Google Gemini AI API

## How to Run
1. Clone this repository
2. Install requirements: pip install flask
3. Run: python app.py
4. Open browser at http://localhost:5000
